# cards-post

Custom **cards** block. Purpose: blog-post-teasers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per post, 2 columns: [picture (optionally linked)] | [eyebrow <p>, <h3><a>title</a></h3>, excerpt <p>, link <p>, date <p>]. Feature option text: [<h2> label, <h3><a>title</a></h3>, excerpt <p>, link <p>]. Pro / highlight text cell: [optional eyebrow <p>Tag 1, Tag 2</p> (split into pills), <h3><a>title</a></h3>, optional excerpt <p>, optional link-only Read More <p> (highlight), last <p> = byline: optional small avatar picture + "Author • 1 month ago"].

## Supported variations

| Variation | Option class |
| --- | --- |
| Feature | `feature` |
| Highlight | `highlight` |
| Pro | `pro` |
