# carousel-hero

Custom **carousel** block. Purpose: blog-hero-carousel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide, 2 cells: [picture] | [<h1> (slide 1) or <h2> title, <p> text, <p><a>CTA</a></p>]. Cells are detected by content (order may be swapped); plain CTA links become pill buttons (first primary, others secondary). Slide 1 image loads eagerly with high priority (LCP); the others lazy-load.

## Supported variations

No variations.
