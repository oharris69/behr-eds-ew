# color-palettes

Custom **color-palettes** block. Purpose: curated-color-palettes.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1 (optional): [h3 + p intro]. Rows 2..n: one cell with a ul of 4 color links whose text is CODE|Name|HEX (main, accent 1, accent 2, trim white). Links not in that form render as a plain swatch showing the link text.
