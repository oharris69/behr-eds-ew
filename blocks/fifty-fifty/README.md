# fifty-fifty

Custom **cards** block. Purpose: paired-promo-cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1 (optional, no picture): [h3 + p intro]. Rows 2..n: [h4 + p > a CTA (+ optional second CTA)] | [picture]. Cells are detected by content (order may be swapped); plain CTA links are rendered as pill buttons (first primary, others secondary). Products option rows: [<p><a>CTA</a></p> (optional h4 above)] | [picture].
