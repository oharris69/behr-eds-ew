# palette-carousel

Custom **carousel** block. Purpose: related-color-browser.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1 (optional): [h2 + p intro]. Rows 2..n: [palette label: Similar | Lighter | Darker] | [ul of color links whose text is CODE|Name|HEX]. Rows may be omitted (e.g. no Lighter); links not in CODE|Name|HEX form show their link text.
