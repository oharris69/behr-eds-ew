# testimonial

Custom **quote** block. Purpose: color-of-the-year-quote.

## Authoring (Document Authoring)

Model: `key-value`

Single block table. Content: one row, one cell of content.

## Content model (key/value rows)

| Key | Value |
| --- | --- |
| eyebrow | short label, e.g. Color of the Year |
| description | the quote |
| attributor-image | square portrait |
| attributor-name | name |
| attributor-description | role |

All rows are optional. The block background, color name and color code come from the page metadata (`rgbhex`, `color-name`, `color-code`).

## Supported variations

No variations.
