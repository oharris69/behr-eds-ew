# hero-spotlight

Custom **hero** block. Purpose: blog-spotlight-hero.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |

## Universal Editor fields

N/A (Document Authoring project)

## Content model

| Hero Spotlight |
| --- |
| picture |
| eyebrow paragraph (optional), h1 title, paragraph (optional), CTA link (optional, bold = primary pill) |

Author `Hero Spotlight (dark)` for the dark option: full-bleed photo with a black rounded
square box top-left, large white title at the top of the box and the paragraph pinned to its
bottom (as on behr.com/inspiration). The default (no option) is unchanged.
